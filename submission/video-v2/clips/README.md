# Recording slots

Capture at 1920×1080 or higher, with the browser zoomed so the product is
legible. Keep the cursor visible. Record a single clean session, then cut it
into these exact named clips; the renderer trims or holds each one to fit.

Keep the recording visually quiet: hide bookmarks and unrelated tabs, disable
notifications, use a neutral cursor, and do not add fake device frames. The
renderer gives product footage the full 1920×1080 canvas. Keep essential UI out
of the bottom 138 px when possible because a small number of editorial proof
